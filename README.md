# Bionic-конвертер EPUB для Kindle

Превращает обычный EPUB в bionic-версию: первая половина каждого слова становится жирной.
Работает с кириллицей.

## Как пользоваться

1. Положите EPUB-файлы в папку `input\`.
2. Дважды кликните **ZAPUSTIT.bat**.
3. Заберите готовые файлы `*_bionic.epub` из папки `output\`.
4. Отправьте на Kindle через **Send to Kindle** (см. ниже).

Первый запуск займёт ~15 сек — создаётся venv и ставятся зависимости. Последующие — 3–10 сек на книгу.

## Как отправить на Kindle Paperwhite

**Единственный рабочий способ** — Send to Kindle. Копировать EPUB напрямую в `documents\` по USB **бесполезно**: Kindle нативно EPUB не открывает, нужен формат KFX (в него Amazon конвертирует автоматически при получении через Send to Kindle).

Варианты:

- **Веб** (проще всего): https://www.amazon.com/sendtokindle → войти в аккаунт → перетащить `*_bionic.epub`.
- **Email**: отправить письмом с вложением на адрес `<имя>@kindle.com` (адрес в настройках Amazon → *Manage Your Content and Devices* → *Preferences* → *Personal Document Settings*). Ваш email отправителя должен быть в белом списке *Approved Personal Document E-mail List*.
- **Приложение Send to Kindle** для Windows — то же самое, что веб, но перетаскиванием прямо с рабочего стола.

Kindle должен быть в Wi-Fi — файл прилетит через минуту-другую.

## Настройка параметров

В `bionicize.py` в начале файла:

- `BOLD_RATIO = 0.5` — доля букв, которые делаются жирными (0.4 — мягче, 0.6 — агрессивнее).
- `MIN_WORD_LEN = 4` — слова короче не трогаем (иначе шумно).
- `SKIP_TAGS` — HTML-теги, содержимое которых не трогать (код, стили, уже жирный текст).

## Через Telegram-бота (для группы «Бубубу»)

Альтернатива локальному запуску — бот сидит в приватной группе, куда Flibusta
Book кидает книги. На каждый `.epub` присылает inline-кнопки «✅ Да / ❌ Нет».
По «Да» — скачивает, гоняет через `process_epub`, reply'ает bionic-версией
на оригинал.

**Лимит:** Bot API не умеет качать файлы >20 МБ. Такие книги бот пометит
предупреждением, обрабатывай их локальным флоу выше.

**Первый запуск локально (для теста):**

1. `pip install -r requirements.txt`
2. Скопировать `.env.example` → `.env`, вписать `BOT_TOKEN` от @BotFather.
3. @BotFather → `/setprivacy` → выбрать бота → **Disable** (иначе не увидит файлы в группе).
4. Добавить бота в группу.
5. `python bot.py` → написать в группе `/id` → бот ответит `chat_id`.
6. Вписать `chat_id` в `.env` как `ALLOWED_CHAT_ID`, перезапустить.

**Деплой на BotHost:** push в `caunt1983-alt/bionic-bot`, задать env `BOT_TOKEN`
и `ALLOWED_CHAT_ID`, entrypoint — `python bot.py`.

## Что внутри

- `bionicize.py` — основная логика (ebooklib + BeautifulSoup + lxml). Импортируется и локальным флоу, и ботом.
- `bot.py` — aiogram-бот для группы.
- `ZAPUSTIT.bat` — локальная запускалка: создаёт venv при первом запуске, потом гоняет скрипт.
- `requirements.txt` — зависимости для pip.
- `.env.example` — шаблон переменных окружения для бота.
- `input\` / `output\` — исходники и результаты локального флоу.
- `.venv\` — локальное виртуальное окружение (создаётся автоматически).
